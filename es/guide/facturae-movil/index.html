Cómo abrir una FacturaE en el móvil

La factura electrónica española (FacturaE) es un archivo XML pensado para que lo lean los programas, no las personas. Si la abres en el móvil sin más, lo normal es ver una larga lista de etiquetas o que no pase nada. Así puedes leerla de forma ordenada.

Opción 1. Abrirla con Daopen

  1. Guarda el archivo en el móvil: desde el correo o la aplicación de mensajes elige "Guardar" o "Descargar" para que quede en la memoria del dispositivo.
  2. Abre Daopen y busca el archivo en la lista, o pulsa el archivo desde el gestor de archivos y elige Daopen entre las aplicaciones que aparecen.
  3. Daopen muestra la factura de forma legible, con los datos, las líneas y los importes ordenados como en un documento normal.
  4. Si necesitas una copia para enviar o archivar, puedes convertirla a PDF y exportarla.

Daopen es un visor de documentos para el móvil: abre PDF, Word, Excel y PowerPoint, y también facturas electrónicas como la FacturaE española. El archivo no se envía a ningún servidor y no hace falta crear una cuenta ni subir nada. Puedes usarlo gratis: los banners aparecen en la lista de archivos y, al abrir un documento, un anuncio a pantalla completa sale más o menos una de cada tres veces. No hay anuncios largos y la pantalla de lectura del documento nunca lleva publicidad. Con un único pago, sin suscripción ni renovaciones, quitas los anuncios para siempre y activas la lectura en voz alta.

Opción 2. Usar el programa de facturación de quien la emitió

Muchas plataformas de facturación generan una versión en PDF a partir de los datos del XML. Si la factura la has recibido a través de una de ellas, puedes pedir o descargar esa versión legible y abrirla con el visor de PDF del móvil.

Opción 3. Usar un visor en el navegador

Existen páginas web que muestran un archivo FacturaE en formato legible. Tienen un inconveniente: tienes que subir la factura a un sitio externo. Si contiene datos fiscales o personales, es preferible una aplicación que abra el archivo directamente en el móvil. Recuerda también que un PDF o una copia impresa sirve para leer la factura, pero el documento original sigue siendo el archivo firmado.

Si no se abre

  • Revisa la extensión: una FacturaE firmada suele terminar en .xsig, y una sin firma, en .xml. Los dos contienen la factura, así que prueba con cualquiera de ellos.
  • Si el archivo llegó dentro de un comprimido, extráelo antes de abrirlo.
  • Vuelve a descargar el adjunto: a veces la descarga se corta y el archivo queda incompleto.
  • No cambies el nombre ni el contenido del archivo: la factura original debe quedar tal cual está.
