카톡으로 받은 hwp 파일, 안드로이드 폰에서 여는 방법

한글(hwp) 파일은 폰 기본 앱으로 열리지 않는 경우가 많습니다. 아래 두 방법 중 편한 쪽을 고르세요.

방법 1. 뷰어 앱으로 바로 열기

  1. 카톡 대화방에서 hwp 파일을 눌러 먼저 내려받습니다.
  2. 내려받은 파일을 다시 누르면 "연결 프로그램" 목록이 나옵니다.
  3. 목록에서 hwp를 읽을 수 있는 뷰어 앱을 고릅니다.
  4. "한 번만"과 "항상" 중 하나를 고르면 앱에서 파일이 열립니다.

hwp를 읽는 뷰어 앱은 여러 가지가 있고, 다오픈도 그중 하나입니다. 다오픈은 PDF, 워드, 엑셀, 한글 파일을 한 앱에서 열 수 있고 무료로 쓸 수 있습니다. 광고는 파일 목록과 문서를 여는 순간에만 나오고, 문서를 읽는 화면에는 나오지 않습니다. 광고 자체가 싫다면 평생 이용권을 한 번 결제하면 광고가 사라집니다.

방법 2. 설치 없이 웹 브라우저로 보기

네이버 웨일 브라우저가 이미 있다면, 파일을 누른 뒤 공유 목록에서 웨일을 고르면 앱 설치 없이 내용을 볼 수 있습니다. 보기만 가능하고 편집은 안 됩니다.

그래도 안 열린다면

  • 파일 확장자가 hwp가 아니라 hwpx인지 확인하세요. 2021년 4월부터 hwpx 형식이 쓰이고 있어서, 쓰는 뷰어 앱이 hwpx를 지원하는지 확인해야 합니다.
  • 뷰어 앱을 최신 버전으로 업데이트하세요.
  • 파일이 중간에 끊겨 내려받아졌을 수 있으니 카톡에서 다시 내려받아 보세요.
