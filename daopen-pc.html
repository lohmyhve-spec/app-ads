다오픈 PC 인쇄 도우미

PC에 USB로 연결된 프린터로 폰 문서를 인쇄합니다. 무료, 회원가입 없음, 윈도우 10·11.

윈도우용 받기 (zip, 약 80MB)

와이파이 프린터는 도우미 없이 다오픈에서 "이 폰으로 인쇄"을 누르면 바로 됩니다.

1. PC에서 처음 한 번만

  1. 프린터가 연결된 PC에서 위 버튼으로 받고, 받은 zip 파일을 열어 DaopenPrintHelper.exe를 더블클릭합니다. (도우미가 알아서 PC 안에 자리를 잡습니다)
  2. 파란 "Windows의 PC 보호" 창이 떠도 놀라지 마세요. 글 아래 추가 정보를 누르고, 새로 생기는 실행 버튼을 누릅니다. ("실행 안 함"는 누르지 마세요)
    ① 먼저 누르기
    Windows의 PC 보호
    추가 정보
    실행 안 함
    ② 그다음 누르기
    Windows의 PC 보호
    실행실행 안 함
    아직 받은 사람이 적은 새 프로그램이라 윈도우가 처음 한 번 띄우는 경고입니다. 바이러스가 아닙니다.
  3. 방화벽 창이 뜨면 액세스 허용을 누릅니다.
  4. 화면에 6자리 연결 코드가 나옵니다. 이후로는 PC를 켜면 도우미가 자동으로 켜집니다.

2. 폰에서 인쇄

  1. 폰과 PC를 같은 와이파이에 연결합니다.
  2. 다오픈에서 인쇄 → PC로 인쇄를 고릅니다.
  3. PC를 고르고, 처음 한 번만 PC 화면의 코드를 넣습니다.
  4. 프린터와 매수를 고르고 인쇄.

안 될 때

• PC가 안 보이면 폰과 PC가 같은 와이파이인지 확인하세요. 그래도 안 되면 주소 직접 입력에 도우미 창에 나온 주소를 넣으세요.

• 백신(알약 등)이 막으면 허용을 눌러 주세요.

• 도우미 창이 안 보이면 받은 파일을 한 번 더 실행하세요. 켜져 있던 창이 앞으로 나옵니다.

• 연결을 끊으려면 도우미 창의 연결 끊기를 누르세요.

문서는 인터넷으로 올라가지 않습니다. 같은 와이파이 안에서 폰에서 PC로만 가고, 인쇄가 끝나면 PC에서 바로 지워집니다.

자주 묻는 질문

여러 PC에 깔아도 되나요?

네. 프린터가 연결된 PC마다 깔면 폰의 PC 목록에 모두 보입니다.

연결 코드를 잊어버렸어요.

도우미 창에 항상 보입니다. 창이 안 보이면 받은 파일을 한 번 더 실행하세요. "새 코드 만들기"로 바꿀 수도 있습니다.

도우미 창을 닫아도 되나요?

네. 창을 닫아도 작업 표시줄(오른쪽 아래)에서 계속 켜져 있고, PC를 다시 켜면 자동으로 켜집니다.

다른 곳에서도 인쇄되나요?

아니요. 폰과 PC가 같은 와이파이에 있을 때만 됩니다. 문서를 인터넷으로 보내지 않기 위해서입니다.

지우려면요?

작업 표시줄의 도우미 아이콘을 오른쪽 클릭해 "윈도우 시작할 때 자동 실행" 체크를 끄고 "종료"를 누른 뒤, 탐색기 주소창에 %LOCALAPPDATA%\DaopenPrintHelper 를 넣어 열리는 폴더를 지우면 됩니다.

• PC not listed? Check that both are on the same Wi-Fi, or use Enter address with the address shown in the helper window.

• If your antivirus blocks it, choose Allow.

FAQ

Can I install it on several PCs?

Yes. Install it on each PC with a printer and they all appear in the list on your phone.

I forgot the pairing code.

It is always shown in the helper window. If you can’t see the window, run the file again. You can also make a "New code".

Can I close the helper window?

Yes. It keeps running in the system tray (bottom right) and starts again when the PC turns on.

Does it work from anywhere?

No. Only when the phone and the PC are on the same Wi-Fi, so your documents never go to the internet.

How do I remove it?

Right-click the helper icon in the system tray, uncheck "Start with Windows" and click "Quit". Then type %LOCALAPPDATA%\DaopenPrintHelper in the File Explorer address bar and delete that folder.

Cài trên nhiều PC được không?

Không. Chỉ khi điện thoại và PC cùng Wi-Fi, để tài liệu không lên internet.

Gỡ thế nào?

常见问题

可以安装在多台电脑上吗？

可以。在每台连接打印机的电脑上安装，它们都会出现在手机的电脑列表中。

忘记连接码了。

连接码一直显示在助手窗口中。看不到窗口时，再运行一次文件。也可以点击“新连接码”更换。

可以关闭助手窗口吗？

可以。关闭后助手仍在任务栏（右下角）运行，电脑开机时也会自动启动。

在任何地方都能打印吗？

不能。只有手机和电脑在同一个 Wi-Fi 时才可以，这样文档不会上传到互联网。

如何删除？

在任务栏右键点击助手图标，取消勾选“随 Windows 启动”并点击“退出”。然后在文件资源管理器地址栏输入 %LOCALAPPDATA%\DaopenPrintHelper 并删除该文件夹。
