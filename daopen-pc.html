다오픈 PC 인쇄 도우미

PC에 USB로 연결된 프린터로 폰 문서를 인쇄합니다. 무료, 회원가입 없음, 윈도우 10·11.

윈도우용 받기 (zip, 약 80MB)

와이파이 프린터는 도우미 없이 다오픈에서 "이 폰으로 인쇄"를 누르면 바로 됩니다.

1. PC에서 처음 한 번만

  1. 프린터가 연결된 PC에서 위 버튼으로 받고, 압축을 풀어 DaopenPrintHelper.exe를 실행합니다.
  2. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
    작은 회사의 무료 프로그램이라 처음 한 번 뜨는 창입니다.
  3. 방화벽 창이 뜨면 허용을 누릅니다.
  4. 화면에 6자리 연결 코드가 나옵니다. 이후로는 PC를 켜면 도우미가 자동으로 켜집니다.

2. 폰에서 인쇄

  1. 폰과 PC를 같은 와이파이에 연결합니다.
  2. 다오픈에서 인쇄 → PC로 인쇄를 고릅니다.
  3. PC를 고르고, 처음 한 번만 PC 화면의 코드를 넣습니다.
  4. 프린터와 매수를 고르고 인쇄.

안 될 때

• PC가 안 보이면 폰과 PC가 같은 와이파이인지 확인하세요. 그래도 안 되면 주소 직접 입력에 PC 도우미 창에 나온 주소를 넣으세요.

• 백신(알약 등)이 막으면 허용을 눌러 주세요.

• 도우미 창이 안 보이면 받은 파일을 한 번 더 실행하세요. 켜져 있던 창이 앞으로 나옵니다.

• 연결을 끊으려면 도우미 창의 연결 끊기를 누르세요.

문서는 인터넷으로 올라가지 않습니다. 같은 와이파이 안에서 폰에서 PC로만 가고, 인쇄가 끝나면 PC에서 바로 지워집니다.

Daopen PC Print Helper

Print documents from your phone on a printer connected to your PC by USB. Free, no sign-up, Windows 10 and 11.

Download for Windows (zip, about 80 MB)

Wi-Fi printers don't need the helper: tap "Print from this phone" in Daopen.

1. On the PC (once)

  1. On the PC with the printer, download the file above, unzip it and run DaopenPrintHelper.exe.
  2. If a blue "Windows protected your PC" window appears, click More info → Run anyway.
    It appears once because this is a free program from a small developer.
  3. If a firewall window appears, click Allow.
  4. A 6-digit code appears. From now on the helper starts with Windows.

2. Print from your phone

  1. Connect the phone and the PC to the same Wi-Fi.
  2. In Daopen, tap Print → Print via PC.
  3. Pick the PC and enter the code shown on the PC (first time only).
  4. Choose the printer and copies, then Print.

Troubleshooting

• PC not listed? Check that both are on the same Wi-Fi, or use Enter address with the address shown in the helper window.

• If your antivirus blocks it, choose Allow.

• Can't see the helper window? Run the file again; the open window comes to the front.

• To unlink phones, click Unpair in the helper window.

Your documents never go to the internet. They travel only from your phone to your PC on the same Wi-Fi and are deleted from the PC after printing.

Daopen PC印刷ヘルパー

PCにUSBでつないだプリンターで、スマホの文書を印刷できます。無料・登録不要・Windows 10/11。

Windows版をダウンロード（zip・約80MB）

Wi-Fiプリンターはヘルパー不要です。Daopenで「このスマホで印刷」を選んでください。

1. PCで最初の1回だけ

  1. プリンターをつないだPCで上のファイルをダウンロードし、展開して DaopenPrintHelper.exe を実行します。
  2. 青い 「WindowsによってPCが保護されました」 画面が出たら 詳細情報 → 実行。
    小さな開発者の無料ソフトのため、最初に1回だけ表示されます。
  3. ファイアウォールの画面が出たら 許可。
  4. 6桁の接続コードが表示されます。以後、PCを起動するとヘルパーも自動で起動します。

2. スマホから印刷

  1. スマホとPCを同じWi-Fiにつなぎます。
  2. Daopenで印刷 → PCで印刷。
  3. PCを選び、最初の1回だけPC画面のコードを入力します。
  4. プリンターと部数を選んで印刷。

うまくいかないとき

• PCが見つからないときは同じWi-Fiか確認し、アドレスを入力にヘルパー画面のアドレスを入れてください。

• ウイルス対策ソフトが止めたら許可してください。

• ヘルパーの画面が見えないときは、もう一度ファイルを実行すると前面に出ます。

• 接続を解除するにはヘルパー画面のUnpairを押します。

文書はインターネットに送られません。同じWi-Fi内でスマホからPCへ送られ、印刷後すぐPCから削除されます。

Daopen PC-Druckhelfer

Drucke Dokumente vom Handy auf einem per USB am PC angeschlossenen Drucker. Kostenlos, ohne Konto, Windows 10 und 11.

Für Windows herunterladen (zip, ca. 80 MB)

WLAN-Drucker brauchen den Helfer nicht: in Daopen „Von diesem Handy drucken“ wählen.

1. Am PC (einmalig)

  1. Auf dem PC mit dem Drucker die Datei oben laden, entpacken und DaopenPrintHelper.exe starten.
  2. Erscheint das blaue Fenster „Der Computer wurde durch Windows geschützt“: Weitere Informationen → Trotzdem ausführen.
    Es erscheint einmal, weil es ein kostenloses Programm eines kleinen Entwicklers ist.
  3. Erscheint ein Firewall-Fenster: Zulassen.
  4. Ein 6-stelliger Code wird angezeigt. Danach startet der Helfer automatisch mit Windows.

2. Vom Handy drucken

  1. Handy und PC mit demselben WLAN verbinden.
  2. In Daopen Drucken → Über PC drucken.
  3. PC wählen und beim ersten Mal den Code vom PC eingeben.
  4. Drucker und Anzahl wählen, dann Drucken.

Wenn es nicht klappt

• PC nicht gefunden? Gleiches WLAN prüfen oder Adresse eingeben mit der Adresse aus dem Helferfenster.

• Blockiert der Virenschutz, bitte Zulassen wählen.

• Helferfenster nicht sichtbar? Datei erneut starten, das Fenster kommt nach vorn.

• Zum Trennen im Helferfenster Unpair klicken.

Deine Dokumente gehen nicht ins Internet. Sie gehen nur im selben WLAN vom Handy zum PC und werden nach dem Druck vom PC gelöscht.
