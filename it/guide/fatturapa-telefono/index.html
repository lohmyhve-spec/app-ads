Come aprire una FatturaPA sul telefono

La fattura elettronica italiana (FatturaPA) è un file XML pensato per i computer, non per essere letto a occhio. Sul telefono, toccandolo, spesso si vede solo una lista di codici o non succede niente. Ecco come leggerla senza complicazioni.

Opzione 1. Aprirla con Daopen

  1. Salva il file della fattura sul telefono: dall'e-mail o dall'app di messaggi scegli "Salva" oppure "Scarica", così resta nella memoria del dispositivo.
  2. Apri Daopen e cerca il file nell'elenco, oppure tocca il file dal gestore file e scegli Daopen tra le app proposte.
  3. Daopen mostra la fattura in una forma leggibile, con dati, righe e importi ordinati come in un documento normale.
  4. Se ti serve una copia da condividere, puoi convertirla in PDF ed esportarla.

Daopen è un visualizzatore di documenti per il telefono: apre PDF, Word, Excel, PowerPoint e anche le fatture elettroniche italiane. Il file non viene inviato a nessun server e non serve creare un account né caricare nulla. Puoi usarlo gratis: i banner compaiono nell'elenco dei file e, all'apertura di un documento, un annuncio a schermo intero appare circa una volta su tre. Non ci sono annunci lunghi e la schermata di lettura del documento è sempre senza pubblicità. Con un unico pagamento, senza abbonamento né rinnovi, togli le pubblicità per sempre e ottieni la lettura vocale.

Opzione 2. Usare gli strumenti dell'Agenzia delle Entrate

Se la fattura è passata dal Sistema di Interscambio, nel portale "Fatture e Corrispettivi" dell'Agenzia delle Entrate puoi consultarla e scaricarne una versione leggibile dal browser del telefono. Serve l'accesso con le tue credenziali, quindi è comodo soprattutto se la fattura è tua.

Opzione 3. Usare il browser

Esistono pagine web che mostrano una fattura XML in formato leggibile. Il file viene però caricato su un sito esterno: per fatture con dati fiscali o personali è meglio preferire un'app che apre il file direttamente sul telefono. Ricorda anche che una copia in PDF o stampata serve a leggere la fattura, ma il documento valido ai fini fiscali resta il file originale.

Se non si apre

  • Controlla l'estensione: una fattura normale finisce con .xml. Se finisce con .xml.p7m, il file è chiuso in una busta con firma digitale e serve un passaggio in più per estrarre il contenuto.
  • Se il file è arrivato in un archivio compresso, estrailo prima di aprirlo.
  • Scarica di nuovo l'allegato: a volte il download si interrompe e il file risulta incompleto.
  • Non rinominare il file e non modificarne il contenuto: la fattura originale deve restare identica.
