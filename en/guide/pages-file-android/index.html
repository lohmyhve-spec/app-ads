How to Open a Pages File on Android

A file ending in .pages is a document made with Apple's Pages word processor on a Mac, iPhone or iPad. Android has no built-in app for this format, so tapping it often shows an error. These options let you read it.

Option 1. Open it with Daopen

Daopen can open your Pages file right on the phone. It also opens Keynote and Numbers files from Apple, along with PDF, Word, Excel, PowerPoint and ODT documents.

  1. Install Daopen and open it.
  2. Save the .pages file to your phone first, for example from the email or chat where you received it.
  3. Find the file in your Downloads folder or in the Daopen file list, and tap it.
  4. If you tapped the file in another app, choose Daopen from the list and pick "Just once" or "Always".

The document is opened on the device, so nothing is uploaded to a server and you do not need an account. If you want to share it with someone who has no Pages app, you can save it as a PDF or export the text. Ads appear in the file list and on about one in three document opens, but never on the screen where you read. A one-time purchase removes ads for good and adds read-aloud, with no subscription.

Option 2. Ask the sender for a PDF or Word copy

The person who made the file can convert it in Pages before sending it again.

  1. In Pages, they open the document and choose Export (on iPhone or iPad it is under Share or the More menu).
  2. They pick PDF if you only need to read it, or Word if you need to edit it.
  3. They send you the new file, which most Android phones can open.

This is the most reliable route for complex layouts, because Pages itself does the conversion.

Option 3. Use a web converter

Some websites convert .pages files to PDF or Word in a mobile browser. This works without installing anything, but you have to upload the file to someone else's server. For contracts, IDs or anything personal, a method that keeps the file on your phone is safer.

If the file still won't open

  • Check that the name really ends in .pages. A .key file is a Keynote presentation and a .numbers file is a spreadsheet.
  • Download the file again, because an interrupted download can leave it damaged.
  • A .pages file is a zipped package. Some email apps or cloud folders show it as a folder or a .zip instead, so ask the sender to compress it or send it as a single attachment.
  • Only open files from people you trust.
