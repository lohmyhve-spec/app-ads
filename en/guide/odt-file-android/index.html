How to Open an ODT File on Android

An ODT file is a text document made by LibreOffice or OpenOffice. Many Android phones have no app that opens it by default, but a few simple options work.

Option 1. Open it with Daopen

Daopen can open your ODT file right on the phone. It also opens ODS spreadsheets and ODP presentations, along with PDF, Word, Excel and PowerPoint.

  1. Install Daopen and open it.
  2. Find the .odt file in your Downloads folder or in the file list, and tap it.
  3. If you tapped the file in another app, choose Daopen from the list and pick "Just once" or "Always".

The file is opened on the device, so nothing is uploaded to a server and you do not need an account. You can also save the document as a PDF or export its text. Ads appear in the file list and on about one in three document opens, but never on the screen where you read. A one-time purchase removes ads for good and adds read-aloud, with no subscription.

Option 2. Open it through Google Drive

  1. Upload the .odt file to Google Drive.
  2. Tap the file and choose to open it with Google Docs.
  3. Google Docs converts the file to its own format so you can read it.

This needs an internet connection, and the conversion can change some formatting, such as fonts or numbering. Without converting, Drive may only show a "No preview" message.

If the file still won't open

  • Check the extension. A file ending in .ods is a spreadsheet and .odp is a presentation, so the app has to support those types too.
  • Download the file again, because an interrupted download can leave it damaged.
  • Only open files from people you trust.
  • If you only need to read it, ask the sender to export the document as a PDF, which almost every phone can open.
